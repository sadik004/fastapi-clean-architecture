# Daily Learning Logs (`docs/days/`)

This directory contains structured daily logs for our 90-Day curriculum.

## Log Format (`day-XX.md`)

Each day's log must record:
1. **Concepts Covered Today**
2. **Architectural Decisions Made**
3. **DSA Time/Space Complexity Enforced**
4. **Summary of Test Results**
5. **Git Commit Suggested**
